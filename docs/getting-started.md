# Getting Started

This section helps you get started with the overview and pre-requisites of the guide.

## Overview

The BookHub API allows developers to access book information from the BookHub catalog.

This guide explains how to make requests to the API and understand the responses.

## How the API Works

The BookHub API uses the request response model.
A client sends a request to an API endpoint, and the API processes the request and returns a response.

For example:

```http
GET /books

This request retrieves books from the BookHub catalog.
